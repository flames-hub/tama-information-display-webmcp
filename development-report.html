04 / RESILIENCE & OLED

止まっても、壊れない。

Network offline
背景と時計はローカル動作。Service Workerがアプリ、既存背景、閲覧済み画像、NARA/GOコピーを保持する。
Weather failure
10分サーバーキャッシュ、最大6時間のstale cache、ブラウザ最終成功データの順で縮退する。
Pixel shift
時計・日付を2〜8pxの範囲で周期移動。システム表示も微細に位置を変える。
Review state
生成95枚のうち記録済み3枚を採用、残り92枚を候補から開始。審査状態とタイプは端末内だけに保存する。
Motion
オーロラ3枚だけにCSS motionを適用し、視差効果を減らす設定では静止する。
Performance
一覧は640×360サムネイルを遅延読込し、4K本体は表示・プレビュー時だけ取得する。
