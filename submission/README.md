# WebMCP Challenge Submission Pack

This directory contains the submission-ready materials for **TAMA Information Display**.

- `submission-checklist.md` — official-requirements checklist and evidence
- `devpost-submission-en.md` — English Devpost story, ready to paste
- `devpost-submission-ja.md` — Japanese reference translation
- `devpost-field-map.md` — field-by-field entry guide
- `youtube-title-description.md` — YouTube title and description
- `challenge-demo-final.mp4` — final demo video, under three minutes
- `challenge-demo-en.srt` — English captions matching the narration
- `challenge-demo-narration-en.md` — exact English TTS narration
- `submission-summary.html` — one-page readiness dashboard
- `final-requirements-audit.md` — final PASS/FAIL review against official requirements

The MP4 is intentionally excluded from the public Git repository; the upload-ready
copy is delivered locally and the Rules require its final URL to be a Public YouTube
video. The source timeline and reproducible capture pipeline remain in this repository.

## Submission freeze

The official FAQ says not to edit the Devpost submission, submitted repository, or live site after the **September 3, 2026, 1:00 PM PDT** deadline and through judging. After final submission, continue development only in a separate fork or branch that is not the submitted version.
